# Прогон «с нуля до первой платной продажи» (N0–N13)

Цель: пройти путь **совсем нового** организатора до **платной** продажи:
1. заявка → одобрение → первый вход;
2. первое мероприятие → бесплатный билет;
3. попытка платной продажи без платежей;
4. **регистрация нового аккаунта Stripe** и **подключение его к Arena**;
5. покупки тестовыми картами, возвраты;
6. уборка.

Этот путь ещё не проходил никто. Чистый прогон 26.10 остановился до продажи. Подключение Stripe новой организацией не проверялось ни разу.

Второй результат так же важен: **замеры подключения Stripe**. Андрей выбирает, что строить:
- экран, где владелец сам вводит ключи, плюс автосоздание вебхука;
- или кнопку «Подключить Stripe» (Stripe Connect).

Решение будет принято по твоим цифрам: сколько минут, сколько действий, сколько ожидания оператора, где организатор застрял.

Запуск — только словом Андрея **«старт прогона с нуля до оплаты»**. Без этого слова не начинай.

Связь с тест-планом платформы: `docs/testing/full_functional_test_plan_2026-11-01.md`, раздел 3.14 (кейсы NEW-01…NEW-15). Соответствие шагов — в конце файла.
