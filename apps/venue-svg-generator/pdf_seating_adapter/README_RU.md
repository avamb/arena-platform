# pdf_seating_adapter

Узкий адаптер векторного PDF (pdfplumber) → seating-json-v1 (диагностика, всегда QUARANTINE).

## Что поддерживается
- На каждой странице ищутся почти квадратные прямоугольники (|w−h|<0.02); берётся единственный самый частый размер (3 знака), нужно ≥2 повторений. Ничья/нехватка повторов — неоднозначность, диагностика, без угадывания.
- Номер места — только если центр слова внутри прямоугольника и это единственное слово, ASCII-целое > 0. Иначе `unknown`.
- Геометрические полосы (band) по центру y с допуском 1 pt; официальные ряды/секции всегда `null`.
- Дубли номеров в полосе, выход за границы, дубли геометрии — помечаются в `quarantine_reasons`.
- Страницы стекаются по вертикали с отступом 40 pt (обратимо: `y_pt = grid_y − page_offset_y`).

## Ограничения
- Нет официальных рядов/секций, `sellable` никогда не true; это не Arena-авторский SVG.
- Диагностический SVG не заявляет совместимость импорта.

## Команды
```
python -m unittest pdf_seating_adapter.tests.test_adapter
python -c "from pdf_seating_adapter import *; m=extract_pdf('source.pdf'); render_diagnostic(m,'diag.svg')"
```

## Статус тестов
Тесты в этой сессии НЕ запускались; их выполнит Codex независимо.


## CLI и независимая приёмка Codex

```powershell
python -m pdf_seating_adapter source.pdf --output-dir pdf_seating_adapter/output/run-001
python -m pytest pdf_seating_adapter/tests -q
```

Каждый запуск требует нового output directory. Существующие каталоги не перезаписываются.
Пакет содержит seating.json, diagnostic.svg, validation-summary.json, provenance.json и manifest.json с SHA-256 выходов.
Manifest остаётся INCOMPLETE до завершения всех выходов; потребитель обязан проверять его статус.
Exit code 2 = успешно создан диагностический QUARANTINE пакет, 1 = ошибка. PRODUCT PASS не заявляется.
Повторяющиеся/неположительные page IDs отклоняются. Прямоугольники при неоднозначном mode сохраняются как rejected evidence.
Официальная identity accuracy UNKNOWN; внешний эталон не использован. Этот модуль не универсальный PDF-конвертер.
Автоматическое определение реальных проходов, официальных секций и рядов пока не реализовано; gaps=[] не утверждает их отсутствия.


Независимая проверка Codex на разрешённой локальной копии: 260 кандидатов (170/90),
260 явно прочитанных номеров; координаты/номера MATCH с предыдущей source-only диагностикой.
Официальных рядов не установлено. Заголовки FLOOR/BALCONY видимы в исходнике,
но их классификация пока не реализована; section_id=null не означает отсутствие секций.
Повторный CLI run в новом каталоге воспроизводит JSON/SVG побайтно; старый каталог отклоняется.
12 тестов автора выполнены независимо; добавлены Codex regression-тесты CLI и validation.
Это PASS для ограниченного диагностического адаптера, НЕ PASS для полностью готовой билетной схемы.


### Подтверждённые подписи из PDF
Опциональные `--section-label FLOOR --section-label BALCONY --decor-label Stage`
ищут точные case-sensitive слова вне посадочных прямоугольников. Отсутствующее
слово не создаётся; конфликт нескольких секций на странице оставляет секцию unknown.
Слова и их bbox сохраняются как evidence. Строки PDF сохраняются как декор без
изменения координат. Официальные ряды остаются unknown; схема остаётся QUARANTINE.
Указанные параметры соответствуют текущему локальному примеру, не универсальным правилам.
