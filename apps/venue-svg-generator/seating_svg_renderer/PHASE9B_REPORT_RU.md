# PHASE 9B — отчёт

Контракт `seating-json-v1` содержит исходную ячейку, worksheet grid geometry,
секцию, геометрический ряд, официальный label и номер места, поэтому его
достаточно для диагностического размещения. Рендерер использует тождественное
преобразование grid → SVG user units и добавляет отступ 2 единицы в `viewBox`;
эталонный SVG для калибровки не читается.

Подтверждённые места становятся отдельными `<circle class="seat">` с
детерминированными уникальными IDs и data-метаданными. Пробелы становятся
`<rect class="aisle-gap">`; `QUARANTINE` и неизвестные позиции не являются
местами и видимы только при явном диагностическом флаге.

Результаты: Hunter — 907 circles; Aribau — 1166 circles. Локальные tests
проверяют XML/viewBox, уникальность IDs, identity `(section,row,seat)`, gaps,
guards для схемы/source-only и fail-closed для неполных данных.

Ограничения: физический масштаб и ориентация не определяются; цены, статусы,
доступность, Bil24/Arena semantics не добавляются. Это diagnostic SVG.
