Проверен один типичный ряд исходного JPG, без API и без установки OCR-библиотек.

## Source-only

Источник: `ChatExport_2026-10-11/photos/photo_63@21-02-2025_11-27-56.jpg` (963×696).

Выбран ряд **4**: номера хорошо читаются, в нём 26 мест.

- Синие посадочные блоки обнаружены связными компонентами маски цвета; найдено 26/26 блоков.
- Для каждого места сохранены исходные координаты в пикселях, bbox, метка ряда, номер и confidence.
- Номера прочитаны по увеличенным глифам в исходном JPG: слева направо `26, 25, …, 2, 1`.
- Номера не получены из порядка кружков: в JSON явно зафиксировано `order_inference_used: false`.
- Пропусков и неоднозначных обозначений в выбранном ряду нет.

Машиночитаемый source-only результат: `output/source-row4-seating.json`.

## Независимая проверка после фиксации source-only

В `maly_sal.svg` найдена единственная группа `#Parter` с 26 кругами и строковой меткой ряда 4.
Координаты сопоставлены явным монотонным affine-преобразованием по оси X и общей координатой Y строки.

- геометрические совпадения: 26/26;
- RMSE после выравнивания: 0.335 SVG units;
- максимальное отклонение: 1.175 SVG units;
- порог сопоставления: 1.5 SVG units;
- geometry precision: **1.00**;
- geometry recall: **1.00**.

Эталонный SVG не содержит индивидуальных номеров мест в `text`, `tspan`, `aria-label`, `data-*` или других стабильных атрибутах кругов. Он содержит номера рядов и легенду, но не seat-number metadata. Поэтому:

- precision/recall номеров: **unknown**;
- exact seat identity accuracy: **unknown**;
- направление нумерации и пропуски в эталоне: **не проверяются**;
- наблюдаемое направление в исходнике: `26 → 1` слева направо, пропусков нет.

Машиночитаемое сравнение: `output/row4-comparison.json`.

## Решение и следующий минимальный шаг

Для геометрии один ряд прошёл проверку (**PARTIAL PASS: geometry**). Причина неполного статуса — отсутствие в эталонном SVG независимой семантики индивидуальных номеров, а не ошибка обнаружения JPG.

Следующий шаг можно ограничить тем же детектором на оставшихся 10 рядах: сохранить 243 source-only мест с исходными номерами и проверить количество, ряды, координаты и дубли. Точность каждой пары «ряд + номер» останется `unknown`, пока не появится эталон с per-seat номерами или отдельная подтверждённая таблица соответствий.

Исходный JPG, `maly_sal.svg`, `arena_new` и результаты Ládví не изменялись. Новые API-запросы не выполнялись.
