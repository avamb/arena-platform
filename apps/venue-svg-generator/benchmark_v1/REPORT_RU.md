# Phase 4 — Benchmark Foundation

Benchmark v1 подготовлен без API, новых зависимостей, UI, router и запуска конвертера. Оценщик принимает единый submission envelope и существующий Seating JSON; провайдер и модель записываются как метаданные. Автоматическое сравнение реализовано через существующий Akropolis evaluator; остальные случаи принимаются без выдуманного score, с `unknown`.

Split проверен по кластерным ID, всем связанным файлам, SHA-256, 17 группам алиасов/версий и трём кандидатам похожих изображений. Известных пересечений нет: development 16, validation 8, test candidates 9, quarantine 37. Полная физическая идентификация не сертифицирована: неизвестные площадки и некоторые алиасы требуют ручной проверки. Test не заморожен и не является ретроспективно невиденным автором.

Из 72 связей исходник → семейство SVG: геометрически проверена 1 (Akropolis A0016 → A0143); 55 контекстных; 16 предположительных, включая 10 предполагаемых версионных соответствий. Только первая допускает автоматический контроль сейчас. Остальным нужны конкретная конфигурация/версия, approved group mapping и якоря; число кругов само по себе не подтверждает число мест.

Структура: `converter_inputs/` — source-only каталог и самостоятельный PDF bundle Akropolis; `evaluator_only/` — ссылки на эталоны и readiness; `output/` — результаты и shortlist. Allowlist не является ОС-песочницей. Будущий генератор допускается только в изолированной среде с выбранным bundle и пустым output; никаких монтирований архива или evaluator. На этом этапе генератор не запускался.

Проверки: 21/21 локальных тестов (7 существующего validator, 5 evaluator, 9 новых инфраструктурных); один полный контроль готового PoC. 260/260 мест, 170 партер + 90 балкон; несовпадений номеров под существующей оценочной проекцией нет. Максимальные отклонения: 0.04030 шага соседних мест для партера, 0.06928 для балкона; оба ниже порога 0.5. Геометрические полосы балкона не объявлены официальными рядами. Официальные ряды/сектора и намеренность пропусков остаются unknown. Ошибок и пересечений исходных seat rectangles не обнаружено.

Время оценки 0.73846 s; историческое время конвертации unknown. API 0 вызовов, стоимость $0; SDK authentication test в стоимость конвертации не включён. SHA-256 всех зарегистрированных артефактов принятого PoC сохранены. Оригинальные PDF/SVG, seating-model.json и arena_new не изменялись. Изменения существующего Python-кода ограничены параметрами путей evaluator и выделением общей структурной проверки из validator; алгоритм извлечения сохранён.

Development shortlist (7): Aribau — XLSX; Hybernia — векторный PDF; Kino MKP — смешанный PDF с двумя залами; Ládví — растровая сетка JPG; Merkin Hall — изображение с нерегулярной нумерацией; Scandic — DOCX и изменённые конфигурации; Nová Spirála — изображения криволинейного зала, неполные варианты. Все требуют независимого уточнения пары перед scoring; Akropolis отдельно остаётся использованным контрольным случаем.

Следующий эксперимент: один source-only JPG Ládví A0149, локальная оценка читаемости и обнаружение мест/OCR без AI. Сначала независимо зафиксировать соответствие версии A0254 и критерии; никакую информацию SVG конвертеру не передавать. Этот этап не подтверждает универсальность и production compatibility.
