# Контекст Venue SVG Generator для проверки SDK

Проект готовит преобразование реальных планов залов в структурированный SVG.
Геометрию и нумерацию необходимо сверять с источником; AI-предположения требуют
отдельного обозначения и проверки человеком.

Авторский SVG Bil24 использует круги мест, группы рядов, подписи сектора,
номера ряда и места, группы PriceCategory и Legend. Платформенный BSS —
отдельное представление с атрибутами sbt:seat, sbt:row и sbt:sect.

Эталон Palác Akropolis: 260 сидячих мест, включая 170 в партере и 90 на
балконе. В эталонном SVG 279 кругов: 260 мест, 15 категорий и 4 элемента
легенды. SVG используется для независимого сравнения результата, а не
копирования при конвертации PDF.

Подробные правила: ../../BIL24_SVG_GUIDE_RU.md. В этом SDK-тесте разрешено
читать только данный файл; переходить по ссылке запрещено. Конвертер ещё
не реализован, и эта проверка не должна его создавать.
