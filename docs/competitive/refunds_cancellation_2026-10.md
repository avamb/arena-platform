# Возвраты, сборы при возврате и платные отмены мероприятий: разведка конкурентов

Дата: 2026-10-12. Статус: черновик, сверено частично (см. раздел «Что не проверено»).

## Коротко

- Возврат стоимости билета при отмене мероприятия организатором почти везде делает сам организатор. Платформа лишь проводит возврат, если организатор его запустил.
- Сбор площадки (booking / service fee) при отмене мероприятия возвращается по-разному: у одних по умолчанию нет (Humanitix, Ticket Tailor по старой справке), у других решает организатор (Billetto), у Eventbrite противоречивые данные.
- Для Arena это значит: политика «сбор возвращаем при отмене мероприятия организатором, при возврате по инициативе покупателя сбор не возвращаем» ближе к Eventbrite, чем к Humanitix, и лучше защищает покупателя; рынок здесь разделён. Это решение владельца, см. раздел «Что это значит для Arena».

Британское право (сводка из поиска, не юр. заключение): при отмене мероприятия покупатель имеет право на возврат номинала билета. Нельзя исключать такой возврат оговоркой в условиях. Вопрос о сборах в источниках остаётся спорным.

## Что это значит для Arena

Текущая модель Arena: прямой мерчант (деньги идут на счёт организатора в Stripe или Flitt), Arena зарабатывает тарифом за билет, который организатор платит ей. Возврат покупателю проходит через таблицу `refunds` (`settlement` = `provider` или `external`, см. AGENTS.md). Отправка возврата провайдеру пока имитируется. Перенос или отмена сеанса (`sessionchange`) не обещает возврат: SCN-12 не построен. Отмена из бота письмами покупателям не отменяет заказы и билеты.

Открытые решения владельца:

1. **Цена билета при отмене мероприятия.** Предлагаю полный возврат всем покупателям без удержаний. Это соответствует британской практике и Eventbrite. Механизма «массовый возврат при отмене» в Arena пока нет.
2. **Сбор покупателя (`fee_percent` канала).** При отмене организатором возвращать полностью, включая сбор. При возврате по инициативе покупателя сбор не возвращать. Для Испании процентный сбор покупателя запрещён (см. [[ticketing-pricing-research-2026-10-10]]), поэтому решение касается и цены.
3. **Тариф Arena за проданный билет.** Конкуренты не возвращают свою комиссию при возврате (Humanitix, Ticket Tailor по старой справке). В Arena тариф платит организатор, так что при полной отмене мероприятия вопрос о возврате тарифа остаётся открытым. Вариант: возвращать тариф за билеты, возвращённые при отмене мероприятия, но не за возвраты по инициативе покупателя.
4. **Ликвидность для возврата.** Humanitix держит возврат в «pending», пока на Stripe хоста нет средств, Eventbrite держит выплату. Arena может показать организатору сумму возвратов до подтверждения отмены, по образцу `change-impact` для сеансов.
5. **Подтверждение отмены.** Бот уже требует ввести слово «CANCEL». Для массовых возвратов тот же шаг нужен в админке.

## Что не проверено

- DICE, Fienta, Tito, Peatix, Showpass: условия на первоисточниках не открывались.
- Eventbrite: канадская справка про возврат сборов взята из поиска, не из страницы.
- Billetto: гайд по отмене взят из поиска, не из страницы.
- Ticket Tailor: отмена всего мероприятия не описана в справке.
- Поиск через Bright Data (`search_engine`) не работает: зона `web_unlocker1` отвечает 200 на чтение страниц, но не отдаёт выдачу Google/Bing. Поиск выполнен через WebSearch.
