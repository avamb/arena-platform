# В какой валюте билетные платформы объявляют свои цены организаторам

Дата: 08.11.2026. Вопрос владельца: в какой валюте международные платформы публикуют прайс своих услуг (комиссии, тарифы), и подбирают ли её автоматически по стране или IP посетителя. Источники: наше исследование цен 188 платформ (`docs/competitive/pricing_2026-10/raw/*.json`) и проверка живых страниц цен 08.11 с испанского IP и из американского сервиса чтения. Метки: [П] проверено на странице, [Д] из нашей базы 188 платформ, [В] вывод.

## 1. Короткий ответ

1. **Автоопределения по IP на страницах цен не видно.** Страницы цен Eventbrite (.com), Ticket Tailor, Luma, Fienta, pretix отдали одинаковое содержимое и с испанского IP, и с заголовками `en-US` и `es-ES`, и из американского сервиса. Страна выбирается вручную или доменом сайта [П]. Оговорка: проверка без cookies и без браузера, редирект после входа или по cookie мог не сработать [В].
2. **Валюта прайса почти всегда валюта страны-основателя платформы или рынка организатора:**
   - Eventbrite .com: доллары (3,7 % + 1,79 $), Luma: доллары (59 $ в месяц), Universe: доллары [П].
   - Ticket Tailor: фунты по умолчанию (0,60 £ за билет), выбор GBP, EUR, USD, AUD, CAD вручную в шапке и в калькуляторе [П].
   - Fienta и pretix: евро [П].
3. **Страны получают свой прайс в местной валюте, и это не пересчёт курса, а отдельные цифры.** Примеры из базы [Д]:
   - Eventbrite: США 3,7 % + 1,79 $; Великобритания 6,95 % + 0,59 £; Ирландия 5,9 % + 0,79 €; Канада 3,5 % + 1,29 C$; Австралия 5,35 % + 1,19 A$; Испания 9 % + 0,19 € (пакет Professional); Германия 5,5 % + 0,99 €.
   - Ticket Tailor, за билет: 0,60 £, 0,85 $, 0,70 €, 1,10 A$, 1,00 C$ (округлённые местные цены, не точный курс).
   - Humanitix: Австралия 4,0 % + 0,99 A$; США 5,0 % + 1,29 $; Великобритания 5,6 % + 0,55 £; зона евро 2,1 % + 0,99 €.
   - Eventim.Light и Weezevent: отдельные сайты и прайсы по странам в EUR, CHF, SEK, NOK, DKK, GBP, CAD.
4. **У большинства платформ одна валюта.** Из 188 платформ только 19 публикуют прайс больше чем в одной валюте, это в основном глобальные самообслуживаемые (Eventbrite, Ticket Tailor, Humanitix, Universe, Billetto, Eventim.Light, Weezevent, DICE, Peatix, TryBooking). Остальные 169 объявляют цену в валюте своего рынка: EUR (51), USD (15), CZK (8), BRL (8), PLN (6), UAH (5), ILS (4), JPY (4), INR (4) и т.д. [Д].
5. **Процентная комиссия ни от какой валюты не зависит.** Валюта нужна только для фиксированной части и месячной платы [В].

## 2. Как это оформлено на сайтах

| Подход | Кто | Как выглядит |
|---|---|---|
| Свой домен или раздел на страну, внутри местная валюта и местные цифры | Eventbrite (.com, .co.uk, .es, .de …), Eventim.Light, Weezevent | Выбор по адресу сайта. С чужого домена показывается тот же прайс, страна не подбирается |
| Ручной переключатель валюты на странице цен | Ticket Tailor (GBP, EUR, USD, AUD, CAD, умолчание GBP) | Один адрес, цифры по каждой валюте |
| Единая валюта для всех | Luma (USD), Fienta (EUR), pretix (EUR), Universe (USD) | Без выбора |
| Таблица по странам в одном документе | Humanitix, Peatix, Billetto | Строки «страна → валюта → ставки» |
| Процент без привязки к валюте, фикс в валюте платёжного шлюза | Tito (3 % с билета, шлюз: «1,4 % + 0,25 €», «2,9 % + C$0,30», «1,4 % + 20p») | Фикс по региону |

## 3. Что из этого для Arena [В]

- Наш рынок: Европа, Израиль, Грузия, диаспора. Реалистичный образец: **один базовый прайс в EUR плюс ручной выбор других валют** (Ticket Tailor), без автоподбора по IP.
- Процентная часть (`fee_percent` канала) валюты не имеет. Фикс и месячные платы (если появятся по спеке биллинга 41/42) нужно объявить в EUR и дать округлённые местные эквиваленты для CZK, CHF, ILS, GBP, USD, GEL, а не пересчитывать по курсу каждый раз.
- Валюта организатора и валюта нашего прайса — разные вещи: организатор продаёт в своей валюте, мы выставляем свой сбор в EUR или в той же валюте, что и его события (это отдельное решение).
- Автоподбор по IP повышает риск ошибки (VPN, перелёты, диаспора в другой стране) и ничего не даёт: ни один из проверенных крупных конкурентов так не делает.

## 4. Чего не знаем

- Не проверено поведение страниц цен в настоящем браузере с cookies и из других стран (VPN): Eventbrite, Humanitix, Universe, Tixr, DICE, Posh, Billetto не отдали цены автоматическому чтению.
- Eventbrite: страница .co.uk показала план Pro в фунтах, но комиссию в долларах. Возможно, шаблон один, а локализован только фрагмент.
- Прайсы региональных платформ (Чехия, Швейцария, Израиль, Грузия, Сербия, Кипр) взяты из нашей базы 09.10, не перепроверены сегодня.
