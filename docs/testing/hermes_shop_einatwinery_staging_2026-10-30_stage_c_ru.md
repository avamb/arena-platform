## Коротко

1. **Витрина — почти всё из ночной волны работает.** Корзина сама убрала товар, переведённый в архив (шаг 90), ограничивает количество остатком с подсказкой «В наличии только N шт.» и лимитом «не больше 24 шт.» (шаг 86). Страница после оплаты первые три минуты говорит «Проверяем платёж…» без кнопки «Вернуться к оплате», сетевые ошибки переживает повторами, через три минуты показывает «Ожидаем оплату» с кнопкой (шаг 96). Перед новым оформлением предлагает вернуться к неоплаченному заказу; четвёртый неоплаченный заказ получает русский текст про «несколько неоплаченных заказов» (шаги 93–94). Ошибка API — «Не удалось связаться с магазином» с кнопкой «Попробовать ещё раз», а не «Страница не найдена» (шаг 97). Turnstile на оформлении невидима. Ворота 18+ помнят ответ в пределах страницы и без хранилища (шаг 92), картинки темы свои (`/theme/brand/…`), `robots.txt` и `sitemap.xml` есть, старые кириллические адреса страниц перенаправляются (шаг 98). Из старого закрыты H-01, H-03, H-05…H-10, H-13, H-15; открыты H-04, H-12, H-14 и половина H-16.
2. **Ивент-центр — заявленные правки на месте.** Карточка товара не теряет правку цены при живом остатке (шаг 89), два варианта с одинаковым именем не сохраняются (шаг 105), настройки предупреждают «Канал продаж не выбран…» и спрашивают перед уходом (шаг 102), заметка к заказу сохраняется по Ctrl+Enter с автором и временем (шаг 104), поиск заказов по номеру и период по суткам Израиля работают (шаг 103). Закрыты E-02…E-05, E-07…E-09, E-12, E-15. Не закрыты E-06 (в тексте курьеру «Israel») и E-11 (в нём нет номера заказа).
3. **Новые находки C-01…C-07.** Самое заметное — превью картинок в карточке товара больше не грузятся вовсе: запрос `media-files/…?w=480` с events-staging режется CORS (C-01, регрессия к 29.10). Панель «У вас уже есть неоплаченный заказ» свёрстана в одну красную строку (C-02). Нет `noindex` на корзине, оформлении и странице заказа, а в `robots.txt` закрыт несуществующий `/order/` (C-03). Снижение остатка после добавления в корзину режет строку молча (C-04). Текст для курьера со стороны сервера — с английским «Israel», «250.00 ILS» и без номера заказа (C-05). Отмена *неоплаченного* заказа требует и слово, и пароль с текстом про «возврат или оплату» (C-06). На телефоне состав заказа ниже кнопки «Оплатить» (C-07).
4. **Пропущено по заданию:** возвраты, ключ идемпотентности возврата, «Отправлен» у частично возвращённого заказа — проверит оркестратор (уже проверено им на № 1000001825).

- Корзина: удалённый из продажи товар исчезает при загрузке; лимит 24 и остаток — подсказками с автоправкой поля; 375 px без прокрутки вбок.
- Страница заказа: «Проверяем платёж…» три минуты без кнопки, повторы при сбоях сети (4 с, 8 с…), затем «Ожидаем оплату» и «Вернуться к оплате»; оплаченный заказ — «Спасибо за заказ!» через ≈6 с после возврата с AllPay.
