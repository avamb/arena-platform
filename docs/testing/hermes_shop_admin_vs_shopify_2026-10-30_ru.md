# Прогон Гермеса: админка магазина в ивент-центре против админки Shopify

Проверял: Hermes (навык `arena-ux-tester`, роль «менеджер магазина, который годами работал в
Shopify и сегодня открыл наш ивент-центр»). Прогон: 29.10.2026, днём по Мадриду, на
events-staging.arenasoldout.com под учёткой менеджера hermes@abhteam.com, организация
«Einat Winery (staging)», сборка ивент-центра из master `071d6fbe` (выкачена утром 29.10).
Вопрос владельца: удобна ли админка магазина с десктопа и с телефона и не идёт ли она
вразрез с привычками человека из Shopify. Правило: отличаться от Shopify можно только в
лучшую сторону.

**Эталон.** Первая попытка открыть админку Shopify магазина einatwinery в Chrome
владельца не удалась (страницы не отдавали ни снимка, ни текста, в дереве доступности
только наложение расширения для чтения «TLDRL / Aa / ✈︎»), и первая версия отчёта была
собрана по справке help.shopify.com и памяти об админке Shopify (Polaris, 2024–2026) и
приложении Shopify для телефона. Во второй заход (владелец вошёл в Shopify сам) живая
админка открылась: список товаров и карточка «Красное сухое "2 Cats"» прочитаны и сняты
только для чтения (снимки 10–14, без данных покупателей), вердикты по товарам сверены с
ними; страница Orders в Shopify дважды отвечала собственной ошибкой «There's a problem
loading this page … 500» и зависала (234 заказа), так что заказы и настройки сверены по
справке и памяти. Ничего в Shopify не нажимал, кроме переходов по страницам. Там, где я
не уверен в текущем виде Shopify, стоит «?».

Что подтвердила живая карточка товара Shopify (снимки 11–14): порядок блоков Title →
Description → Media → Category → Price (Compare-at, Unit price, Charge tax, Cost per item)
→ Inventory (таблица Unavailable / Committed / Available / On hand по локациям, SKU,
Barcodes, «Sell when out of stock») → Shipping (вес, упаковка) → Variants («Add options
like size or color») → Category metafields → Search engine listing → Status → Publishing
→ «Sales past 90 days» → Product organization (Type «Wine», Vendor «Einat Winery»,
Collections «Наши вина», Tags) → Theme template; наверху «View» (открыть на витрине),

товара «Красное сухое 2 Cats» — SEO-заголовки Shopify импорт не перенёс (см. A-04).

## Коротко

Человек из Shopify узнает нашу админку: те же три статуса товара (черновик / в продаже /
в архиве), те же опции и варианты с ценой и старой ценой, тот же остаток с «доступно»,
тот же список заказов с покупателем и суммой, тот же возврат из карточки заказа. Слова
по-русски, чего у Shopify нет вовсе (админка Shopify не знает ни русского, ни иврита).
Экран настроек проще, чем шесть разделов Settings в Shopify, а «Скопировать для курьера»
у Shopify нет без приложения.

Три места идут вразрез с привычкой:

1. **Карточка товара собрана в другом порядке и сохраняется тремя кнопками.** В Shopify
   медиа сразу под описанием, цена на уровне товара, одна кнопка Save наверху и защита от
   ухода с несохранёнными правками. У нас картинки в самом низу и только после первого
   сохранения, цена внутри «Вариант 1» даже у товара с одной версией, и три кнопки:
   «Сохранить товар», «Сохранить варианты», «Сохранить описание» (A-01, A-02, A-03).
2. **С телефона остаток не поправить за два касания.** Карточка товара на 375 px — 5,1
   экрана, поле «Остаток» на 3,6-м экране, верхнее меню занимает 44 % первого. В
   приложении Shopify менеджер правит остаток с главной вкладки «Товары» без карточки
   (A-15, E-12).
3. **Список товаров и список заказов без того, чем в Shopify пользуются каждый день:**
   вкладок «К отправке / Не оплачены», счётчиков, массовых действий, миниатюр, поиска по
   товарам (A-06, A-07, A-08, E-08, E-09).

## Что у нас лучше Shopify (не сломать при правках)

- «Скопировать для курьера» и честный запасной вариант, когда буфер обмена закрыт.
- Остаток с подсказкой «В неоплаченных заказах: 0 · Доступно: 82» прямо под полем;
