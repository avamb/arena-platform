## 6. Ручная приёмка на тестовой организации (ABH TEAM)

1. Ивент-центр → «Данные организации» → «Подключить Telegram». На странице видны кнопка и QR-код.
2. Открыть ссылку на телефоне с Telegram. Бот спрашивает «Подключить этот Telegram к «ABH TEAM»?»
   и показывает замаскированную почту.
3. Нажать «Подключить». Бот открывает меню ABH TEAM. Страница сама пишет «Готово!».
4. Открыть ту же ссылку ещё раз. Бот отвечает, что ссылка больше не работает.
5. Мастер → «A new venue» → страна, город, адрес, часовой пояс, места → две даты → «Создать
   мероприятие». В списке площадок появилась одна новая площадка. Мероприятие — черновик с двумя датами.
6. Удалить тестовое мероприятие. Тестовая площадка останется: удалить её в карточке площадки, если мешает.
