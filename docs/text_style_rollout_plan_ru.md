| Волна | Что | Почему сначала |
|---|---|---|
| 3.1 | Пять примеров из раздела 6 стандарта (`too_many_messages`, `err_capacity`, `tz_suggest_note`, `ask_poster`, `ses.type_ask`) | Показать эффект. Меняются en, ru, es, cs, he |

3. Прогнать `go test ./internal/platform/i18n` и `go test ./internal/platform/eventbot/...` (тесты полноты и рендер каждого шага).
4. Обновить базу: `ARENA_STYLE_WRITE_BASELINE=1 go test ./internal/platform/i18n -run TestTextStyle_Catalogs`, закоммитить файл. Число должно уменьшиться.

## Шаг 4. Расширить область проверки

После шага 3 расширить `styleScopePrefixes`:

- затем описания в `openapi.yaml` (отдельный проход по YAML, только `description` и `message`).
