# Формат афиши мероприятия (решение 28.09.2026)

Схема для дизайнера: `poster_format_spec_4x5.png` (рядом с этим файлом).

## Решение

- Одна афиша на мероприятие — и для сайта, и для Instagram/Facebook. Старый формат Bil24
  (640×670) для новых мероприятий больше не используется.
- Принимаем два формата: **4:5, 1080×1350 px** (основной, формат ленты Instagram/Facebook)
  или **квадрат 1080×1080 px**. PNG или JPG, до 5 МБ, ширина не меньше 1080 px.
- Безопасная зона 4:5: центральный квадрат 1080×1080 минус 60 px от краёв (960×960).
  Всё, что должен прочитать покупатель, — только там.
- Может быть срезано: 135 px сверху и снизу (квадратная карточка в списке мероприятий
  на сайте) и около 34 px по бокам (сетка профиля Instagram, превью 3:4). Там только фон.

## Где как показывается

| Место | Как |
|---|---|
| Лента Instagram / Facebook | целиком, 4:5 |
| Страница мероприятия на сайте | целиком, 4:5 |
| Карточка в списке мероприятий | центральный квадрат |
| Ссылка в Facebook / WhatsApp | сайт собирает 1200×630: афиша на размытом фоне |

## Что делать на сайтах

1. Мастер «+ Ивент»: афиша загружается файлом, мастер проверяет пропорции (1:1 или 4:5)
   и ширину, иначе предупреждает.
2. Lampyris: карточки уже квадратные, страница мероприятия показывает афишу целиком.
3. Vino&Co: карточки сейчас растягивают афишу в рамку 640×670 (`object-fit: fill`) —
   перевести на центральный квадрат без искажения; страница мероприятия — целиком.
4. Картинка для ссылки 1200×630 собирается автоматически.
